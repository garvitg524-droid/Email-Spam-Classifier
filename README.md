# 📧 Email Spam Detection using Machine Learning

## Project Overview
This project is a Machine Learning and Natural Language Processing (NLP) application designed to classify text messages or emails as **Spam** or **Not Spam (Ham)**. It demonstrates text preprocessing, feature extraction, model training, evaluation, and deployment.

## Objectives
* Detect spam messages automatically
* Apply Natural Language Processing techniques
* Compare classification algorithms
* Build an interactive prediction interface

## Key Features
* Text cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* TF-IDF feature extraction
* Machine Learning model training
* Spam prediction interface
* Streamlit web application

## Project Structure
```text
Email-Spam-Detection/
├── app.py
├── model.pkl
├── vectorizer.pkl
├── spam.csv
├── requirements.txt
└── README.md
```

## Technologies Used
* Python
* Streamlit
* Pandas and NumPy
* NLTK
* Scikit-Learn
* WordCloud
* Matplotlib

## Data Preprocessing
* Text normalization and lowercase conversion
* Punctuation and stop-word removal
* Tokenization and stemming
* Duplicate removal

## Feature Engineering
* Bag of Words (BoW)
* TF-IDF Vectorization

## Models Evaluated
* Multinomial Naive Bayes
* Bernoulli Naive Bayes
* Gaussian Naive Bayes

**Selected Model:** Multinomial Naive Bayes (identified as the best-performing model in the original project).

## Application Workflow
1. User enters a message
2. Text is preprocessed
3. TF-IDF vectorization is applied
4. Trained model analyzes the message
5. Prediction is generated
6. Result is displayed as Spam or Not Spam

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Future Enhancements
* Deep Learning integration
* Real-time email filtering
* Multi-language spam detection
* Cloud deployment
* Advanced NLP models

## Conclusion
This project demonstrates a practical application of Machine Learning and NLP for spam message detection through an easy-to-use web interface.
